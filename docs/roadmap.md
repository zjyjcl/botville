# botville 路线图（M0–M4）

来源：产品方案 v0.6。四条线各 1 人全职粗估，M0–M3 约 26 周，含 M4 约 34 周。

| 里程碑 | 目标 | 周期 |
|---|---|---|
| M0 准备 | 服务器兼容性验证、仓库骨架、网关契约与 OpenAPI 初稿、SwiftUI 原型 | 第 1–2 周 |
| M1 最小可用 | Synapse+Postgres 部署、个人 AI 助手接入、Element 聊天、网关雏形、通知并行期 | 第 3–6 周 |
| M2 网关·记忆·社交 | 三层限额、四层记忆、简单接入、签名/动态/配对、AI 关系与多 AI 群、动态界面、苹果 App α | 第 7–19 周 |
| M3 迁移与开源 | 通知卡片与授权上线、中枢下线、安装向导、TestFlight β、文档发布 | 第 20–26 周 |
| M4 小镇扩展 | 小镇：用户关键图生成素材（画风自选）、规则移动作息、模型社交判断、事件联动、本服所有者进镇、SpriteKit 与网页版 | 第 27–34 周（约 8 周） |
